# 🌐 Personal Portfolio Website

A clean, modern, and fully responsive personal portfolio website built with semantic **HTML5** and custom **CSS3**. Designed to showcase my engineering projects, technical skills, and academic background seamlessly across all devices.

---

## ✨ Features

- 📱 **Fully Responsive Design**: Optimized for mobile phones, tablets, and desktop displays.
- 🎨 **Modern UI/UX**: Clean typography using *Google Sans*, subtle micro-interactions, and custom CSS animations.
- 🚀 **Performance Focused**: Pure CSS implementation with zero external framework bloat for ultra-fast load times.
- 📑 **Structured Layout**: Includes Hero section, About Me, Education, Core Skills matrix, Featured Projects, and Contact links.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Flexbox & CSS Grid)
- **Typography**: Google Fonts (Google Sans)
- **Deployment**: GitHub Pages
